Programmatic exports: `runCorpus(options)`, `verifyCorpus(absoluteDirectory)`, `main(args)`. Optional programmatic `limits` only tightens validated fixed maxima, never enlarges them. CLI prints total/rendered/failed/verified JSON, exits1 if any native fixture failed (even when hash closure is valid); infrastructure/manifest errors also exit1. Native positive cases always require exit0 and nonempty exported bytes. A failed case records its exact process status, bounded stdout/stderr, source and partial SVG if within limits, then continues. Missing/empty SVG is failed. Oversized SVG is discarded from this exclusively owned fresh output and its byte count/outcome is retained; it is never hashed or presented as an admitted artifact.

Optional original manifest is copied/hashes retained as `original-admission.json`. Matching is filename (extension retained) plus exact source SHA; duplicate/mismatched source/status rejects. Reference `error` and native `rendered` remain independent fields (e.g. core-plugin boundary); an original error NEVER authorizes native failure. Unmatched cases say `not-observed`. This copies original status provenance only; verification of the original SVG/metrics artifact closure remains a separate oracle evidence gate. Native driver does not authenticate the original renderer or label expected original errors from a hardcoded name list.

Per case: exact hashed source, `.stdout.log`, `.stderr.log`, `.status.json`, and produced `.svg` (including bounded partial SVG from nonzero exits). Manifest also records exact binary bytes/hash, limits, Node/platform/architecture, UTC run timestamps, child environment policy and actual result counts. No family or measurement telemetry is inferred from fixture names. `check` revalidates all retained artifacts, rejects missing/extra/duplicate/traversing/symlink paths, changed bytes/lengths and inconsistent case/status/source/original/summary tables. The write-once manifest is not a cryptographic signature; retain its externally reported SHA in controller evidence.

Bounds: at most256 cases/512 entries per source directory;256KiB each source/16MiB aggregate snapshot;16MiB SVG;1MiB combined retained stdout/stderr per child;64MiB aggregate artifacts INCLUDING manifest;4MiB manifest;256MiB viewer hash input streamed in64KiB chunks. Render phase deadline300s, per-case15s or remaining aggregate time; children get PATH empty and DISPLAY/WAYLAND_DISPLAY removed. Each child has its own process group on Unix, empty stdin and bounded output collection; output-file size is watched every20ms. SIGKILL on timeout/flood/oversized output plus awaited `close`; group kill also covers a leader which exited while same-group descendants retain pipes. This is developer trusted-binary process management, not an OS filesystem/network/memory/file-quota sandbox. File writes can transiently exceed a poll threshold before kill/discard. Preflight source/binary/hash filesystem reads have byte bounds, not hard I/O deadlines. Linux is tested; other platform process behavior is unverified.
