## Actual grammar/runtime cutover and removed syntax

Runtime route:

```
preprocess::Processor::define(raw, whole authored declaration span)
  -> parser::parse_definition
  -> borrowed SourceView + bounded custom spanned token buffer
  -> pre-entry DEFINITION_ADMISSION
  -> generated DefinitionParser::parse(Context, CheckedTokens)
  -> typed borrowed DefinitionSyntax
  -> unchanged immutable registry / eager freeze evaluator / origin storage
```

The genuine production in `parser/grammar/definition.lalrpop` consumes `!define`, required horizontal separator, name, required separator, literal and complete EOF. Its fallible action receives borrowed typed name/literal values and generated byte locations; it never receives/reparses a raw declaration. The custom lexer recognizes primitive ASCII name lexemes, header trivia and explicitly owned remaining literal bytes. It carries exact absolute UTF-8 byte offsets. Only four token variants exist; no future-family variants or `Line*` forwarding exist. There is one parser invocation, no retry/fallback and no recovery-and-render path.

Removed `Processor::define`'s declaration-prefix stripping, manual name-end extraction, tail/separator parsing, literal-edge extraction, name/literal syntax checks and pointer-offset span reconstruction. Primitive validation now belongs to the generated parse's bounded typed action/lexer. The preprocessor's existing command-classification/original-source ownership guard remains; it does not extract the declaration's name/literal.

The whole original declaration `Definition.span` remains unchanged. Evaluation calls `expand(syntax.literal, syntax.literal_span, Some(id))` directly, using the actual generated literal span. Name lookup, duplicate/freeze behavior, copying/retention bounds, registry insertion, original cursor, no-rescan, capabilities and raw/comment ownership are unchanged. All42 public constants and eight private preprocessor origin/bounds controls pass unchanged, including predecessor atomic two-byte comment-delimiter regressions.

`!define WHO World` directly asserts WHO/World, name bytes8..11 / column9 and literal12..17 / column13. Nonzero source-base and UTF-8 assertions check exact byte spans; a hand-derived preservation control accepts Unicode leading indentation and retains Unicode RHS edge whitespace while trimming only ASCII space/tab at literal edges. Additional contracts cover ASCII64-byte/nonempty names,16KiB literals, forbidden controls/odd continuation slashes/parameterized definitions, trailing newline/complete EOF, source-span arithmetic, tiny work/stack limits and cancellation.
