# Native diagram coverage

Coverage basis: `3478bbd`, 2026-10-23, including bounded advanced state and its declaration-name correction. This maps the checked-in implementation, rather than claiming complete Mermaid or PlantUML compatibility. The final coherent corpus and Linux gallery have completed, with their structured evidence archived at `8d41271`. Two scoped independent final reviews found no concrete Blocker or Important issue; neither establishes full upstream compatibility or pixel parity.

Post-checkpoint viewer change: the standalone viewer embeds a DOT helper built from [pinned Graphviz 16.1.0 source](vendor/graphviz/README.md) and runs it as a bounded separate process for PlantUML UML/description and state graph layout. The pure engine API defaults to Dagre. Headless `--output FILE.png` and `--compare-png REFERENCE.png` enable exact RGBA pixel comparisons. The archived corpus, gallery and final reviews predate these changes; their counts and verdicts are historical rather than validation of bundled DOT output. See [the viewer commands](README.md) and the [PNG CLI regression](viewer/tests/png_cli.rs).

Use [README](README.md) for build, run, export and capture commands, [examples](viewer/src/examples.rs) for selectable demonstrations, and the linked tests/fixtures for exact executable inputs. A demonstration is one admitted case, not a family-wide grammar guarantee.

| Evidence | Establishes | Does not establish |
| --- | --- | --- |

| Measurement/geometry assertions | Tested coordinates, bounds, proportions, containment and selected native glyph spacing. | Universal font, browser or original-renderer equivalence. |

| Source/license audit | Recorded local archive/source bytes, scoped destinations, credits, notices and dependency closure. | Universal compatibility or external authentication of every upstream artifact. |

## Mermaid

The baseline is published **Merman 0.9.2**, targeting **Mermaid 12.1.0**, with the four audited changes in [the vendor patch ledger](vendor/PATCHES.json). The additions include released 12.2 `mindmap.colorBy: depth` and coherent SVG usecase/tree font declarations; they do not make this a full Mermaid 12.2 port. [Vendor provenance](vendor/README.md) records archive/VCS identities and embedded-source notices.

The following **37 native variants** have executable label/finite-positive-SVG/usvg admission controls in [families.rs](engine/tests/families.rs), using [the Mermaid fixtures](fixtures/mermaid): agentflow, architecture, block, C4, class, Cynefin, ER, eventmodeling, flowchart, Gantt, git graph, info, Ishikawa, journey, Kanban, mindmap, packet, pie, quadrant, radar, railroad IR, railroad EBNF, railroad ABNF, railroad PEG, requirement, Sankey, sequence, state, swimlane, timeline, tree view, treemap, usecase, Venn, Wardley, XY chart and ZenUML. [Mermaid contracts](engine/tests/mermaid.rs) and [compatibility tests](engine/tests/compatibility.rs) add focused behavior/error checks. Exact sample grammar is available in each fixture; this list is admission coverage, not exhaustive semantic coverage of every variant.

Graph layout defaults to Dagre; architecture retains specialized COSE/fCOSE behavior. Explicit unavailable layout requests, including ELK, fail. Browser/default-ELK geometry, foreign-object text and unsupported specialized bbox/wrap metrics differ. Math/embedded math fonts, system-font/clock/random/timezone backend adapters and binary export features are disabled; authored math that requires unavailable typesetting fails. Runtime rendering launches no Node, browser or KaTeX helper. Enabled dependency features are pinned in [Cargo.toml](Cargo.toml).

Original Mermaid 12.2 core rendered 36 of these fixtures in the final corpus; ZenUML failed detector registration. Its separate optional plugin was not installed or tested in that reference run. Native ZenUML admission therefore is not evidence of parity with an original ZenUML plugin. Old original artifact sets had a documented overwrite/repeatability inconsistency; the final corpus below uses fresh exclusive directories and independently matched source hashes.

### Explicit non-admission and state frontier

Unimplemented syntax fails rather than returning partial diagrams. No native formula typesetting is claimed: original math/LaTeX reference cases degraded to raw formula text when TeXFormula was missing. Ditaa's import is not functioning MIT wrapper/factory admission evidence; chronology's factory registration is commented out. Raw DOT, other languages, utility/help/font/icon outputs and IVE markdown/product integration are outside this workspace's admitted renderer scope. No PlantUML GPL/EPL/ELK/Smetana implementation or untraced theme/icon/font/math asset is imported; the separately vendored EPL-2.0 Graphviz helper is described above.

**Advanced state: integrated bounded subset at `95908d1`.** Composite `--` regions stack and `||` regions sit side by side; mixed separators keep the first axis, including empty/nested regions. Initial/final and shallow/deep `[H]`/`[H*]` singletons belong to their owning scope/region. Composite suffixes such as `S[H]` and `S.N[H]` resolve that composite's history. One supported `<<choice>>`, `<<junction>>`, `<<fork>>`, `<<join>>`, `<<history>>`, `<<history*>>`, `<<start>>` or `<<end>>` retains named identity and paints the actual shape. Fork/join preserve explicit edges without degree rules or broadcast; history is notation, not execution/replay.

Ordinary later-region endpoints require direct region ownership. Cross-region and later-to-outer transitions reject; first-region escapes and admitted history/container edges use bounded explicit routes. Obstructed routes or overlapping boundary labels fail with statement locations. Root separators, legacy `==sync==`, ports, custom/additional stereotypes, pseudostate descriptions, styled/directional transitions and qualified declarations remain unsupported. Visible separators on boundary links and native routing differ from some original layouts; general state/pixel parity is not claimed.

Unquoted state declaration identities contain letters, numbers or underscores. At `3478bbd`, unquoted `history*` declarations reject with the offending name/location, while quoted `"history*"` remains an ordinary name and `<<HiStOrY*>>` remains a supported deep-history kind. The [direct generated state controls](engine/src/plantuml/parser/state.rs) distinguish stereotype values from identities; this correction does not add a new family or execution semantics.

The [advanced-state example](fixtures/plantuml/stateadvanced.puml), [public extension contracts](engine/tests/plantuml_state_extension.rs) and native geometry tests cover region order/identity, scoped history, shapes, endpoints, bounds and cancellation. Its recorded Linux capture reports 9 native measurements/zero fallback with dashed regions, H, choice and fork/join visibly present. The source audit records 293 selected MIT source/ZIP hashes, 58 fixtures and 58 native modules; these inventory figures do not imply complete syntax or independent review. The [state checkpoint](evidence/current/state/task-3b2-report.md) and [integration/name correction](evidence/current/state/task-3b2-integration-followup-report.md) are durably archived alongside the capture metadata below.
