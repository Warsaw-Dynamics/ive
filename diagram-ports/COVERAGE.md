Preparation snapshot: `8a2babb`, 2026-10-23. This maps the checked-in bounded implementation, rather than claiming complete Mermaid or PlantUML compatibility. Advanced state, the final coherent corpus, the final evidence archive extension and whole-branch review are **pending**. Use [README](README.md) for build, run, export and capture commands, [examples](viewer/src/examples.rs) for selectable demonstrations, and the linked tests/fixtures for exact executable inputs. A demonstration is one admitted case, not a family-wide grammar guarantee.

## What each kind of evidence establishes

| Evidence | Establishes | Does not establish |
| --- | --- | --- |
| Parsing/admission and negative controls | Whole input is admitted or fails within the implemented subset. | All upstream syntax is implemented. |
| Typed-model/topology assertions | Tested identities, source order, ownership, endpoints and control/data relationships. | Equivalent routing or appearance. |
| Measurement/geometry assertions | Tested coordinates, bounds, proportions, containment and selected native glyph spacing. | Universal font, browser or original-renderer equivalence. |
| Native app-frame capture | The selected example reached actual viewer paint on the recorded platform, with recorded native/fallback counts. | Uncaptured cases, other platforms, or original pixel parity. |
| Original-renderer output | Reference admission and the recorded original output/configuration. | Native support or native fidelity. |
| Corpus export manifest | Exact source/output/binary hashes and per-case CLI outcomes for that run. | Semantic/topology, ink, UI or pixel checks absent from the manifest. |
| Source/license audit | Recorded local archive/source bytes, scoped destinations, credits, notices and dependency closure. | Universal compatibility or external authentication of every upstream artifact. |

## Mermaid

The baseline is published **Merman 0.9.2**, targeting **Mermaid 12.1.0**, with the four audited changes in [the vendor patch ledger](vendor/PATCHES.json). The additions include released 12.2 `mindmap.colorBy: depth` and coherent SVG usecase/tree font declarations; they do not make this a full Mermaid 12.2 port. [Vendor provenance](vendor/README.md) records archive/VCS identities and embedded-source notices.

The following **37 native variants** have executable label/finite-positive-SVG/usvg admission controls in [families.rs](engine/tests/families.rs), using [the Mermaid fixtures](fixtures/mermaid): agentflow, architecture, block, C4, class, Cynefin, ER, eventmodeling, flowchart, Gantt, git graph, info, Ishikawa, journey, Kanban, mindmap, packet, pie, quadrant, radar, railroad IR, railroad EBNF, railroad ABNF, railroad PEG, requirement, Sankey, sequence, state, swimlane, timeline, tree view, treemap, usecase, Venn, Wardley, XY chart and ZenUML. [Mermaid contracts](engine/tests/mermaid.rs) and [compatibility tests](engine/tests/compatibility.rs) add focused behavior/error checks. Exact sample grammar is available in each fixture; this list is admission coverage, not exhaustive semantic coverage of every variant.

Graph layout defaults to Dagre; architecture retains specialized COSE/fCOSE behavior. Explicit unavailable layout requests, including ELK, fail. Browser/default-ELK geometry, foreign-object text and unsupported specialized bbox/wrap metrics differ. Math/embedded math fonts, system-font/clock/random/timezone backend adapters and binary export features are disabled; authored math that requires unavailable typesetting fails. Runtime rendering launches no Node, browser or KaTeX helper. Enabled dependency features are pinned in [Cargo.toml](Cargo.toml).

Original Mermaid 12.2 core historically rendered 36 of these fixtures; ZenUML failed detector registration. Its separate optional plugin was not installed or tested in that reference run. Native ZenUML admission therefore is not evidence of parity with an original ZenUML plugin. Old original artifact sets had a documented overwrite/repeatability inconsistency; their old hash summaries must not stand in for the pending fresh final corpus.

## PlantUML

Only authorized **PlantUML MIT 1.2026.9** sources supply translated behavior. Models and native layouts remain separate from Mermaid. Generated structural entries, their exact grammar/output hashes and registrations are indexed in [the parser inventory](provenance/plantuml-parser.json), [generated manifest](engine/src/plantuml/generated/manifest.json), [admission proofs](provenance/plantuml-parser-admission.md) and [responsibility ledger](provenance/plantuml-parser-responsibilities.json). Ordinary builds use checked-in generated Rust, with no runtime generator or legacy parser fallback.

The evaluated `puml` v0.2.6 candidate is excluded under the [recorded implementation-lineage adoption hold](../docs/superpowers/plans/2026-10-23-puml-provenance-audit.md); it is not this backend or a recommended accepted-origin dependency. The native implementation uses the separately authorized MIT source ledger instead.

## Runtime, fonts and geometry

| Boundary | Current contract |
| --- | --- |
| Engine | GPUI-free caller-memory API; no file/network/environment/ambient clock/JVM/JS/browser/dot/git execution. Default256KiB source,16MiB SVG,10,000 model items, depth64,5,000,000 work and cooperative10s. Caller limits validated; cancellation and work/storage checks remain phase-specific. |
| Worker | Same-binary isolated process; bounded protocol/query/output, independent10s watchdog with kill/reap, Unix2GiB address-space ceiling. This is not an OS filesystem/network sandbox. |
| Host | Native font measurement, SVG parsing/font loading and rasterization have cooperative checks and explicit XML/tree/point/bitmap/effect limits; worker deadlines do not make every host library call preemptible. Raster4096 per axis/4,194,304 pixels, logical axes1,000,000, scale≤8. |
| Platforms | Linux runtime/captures/native font and worker-fault evidence exists. macOS features/Unix implementation are present but runtime/font/capture enforcement is not verified here; non-Unix has no equivalent OS address-space ceiling. No Windows/platform-wide verification claim. |
| Native measurements | Actual installed-font advances/line metrics for supported operations; unsupported bbox/wrapping/offset operations explicitly fall back. Counts report actual calls/fallbacks, not universal native layout. |
| Text | Runs measure/paint with matching text/style segmentation; cache includes all shaping/paint axes. Baselines still approximate descent with font-size/4.5. Generic/missing-family choice can differ between native and SVG, despite specific installed-font/glyph controls and the document serif fix. |
| Paint versus export | Viewer may expand the canvas for safe text-only overflow without repositioning nodes. Clips/effects/nontext edge exposure preserve original bounds or reject. This does not fit text into nodes or change deterministic headless SVG export. |
| Fidelity | Dagre/native layouts, curves/ports/symbols/themes/spacing and host/browser fonts differ. Full-color comparison against pinned pgui SVG paint is not pixel equivalence with Mermaid/PlantUML originals. No universal original geometry, native ink/baseline or DOM bbox claim. |
