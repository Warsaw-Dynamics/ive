# Definition parser admission

This proof covers only `parser/grammar/definition.lalrpop` and its mechanically generated LALRPOP 0.23.2 output, whose exact grammar/generated SHA256 values are retained in `generated/manifest.json`. Changes to this grammar or generator require renewed inspection of this proof and `context::DEFINITION_ADMISSION`; admission for future grammars must be established separately.

The custom lexer retains at most five borrowed spanned tokens in a single exact-capacity five-element buffer: directive, ASCII horizontal separator, ASCII name, separator and the owned same-line literal. Only leading indentation uses Unicode whitespace, as the predecessor's `trim_start` did. RHS edge trimming remains ASCII space/tab only. Newline cannot be swallowed into a literal; actual tokens and required separators feed the generated production, which owns declaration order and complete EOF. No statement is forwarded to a prior syntax parser.

The inspected seven-state table has only five positive shift transitions (0→2→3→4→5→6). All token-lookahead reductions are absent. At EOF state6 performs the five-symbol definition reduction, returning to state1, which performs the accepting start reduction. Generated location helper reductions exist in emitted functions but no reachable table entry invokes them. There is no nullable recursive cycle. `uses_error_recovery()` is false: no dropped-token accumulation or recovery model is possible. Success uses at most six live states and five symbols; the exact runtime starts with `vec![start_state]` and `vec![]`. Rust vector growth for the concrete i8 state and nonzero symbol types stays within eight state and eight symbol slots, including that initial fixed allocation.

Failure diagnostics call `__expected_tokens_from_states`: at most four terminal probes, each copying at most six states and simulating at most two reductions. The copy is dropped between probes; at most four bounded terminal strings and four String-vector slots are admitted conservatively. No recursive generated builder or retained syntax list exists. The successful fixed borrowed syntax result carries name/literal and both authored spans. Its action checks cancellation/work before returning; the unchanged evaluator charges definition/model and retained text before copying.

Before `DefinitionParser::parse` can allocate, admission validates token count, thirty stack/diagnostic slots against work capacity, a conservative concrete-type byte bound against `source_bytes × 256`, and reserves all five shifts, two reductions, sixteen stack slots, fourteen diagnostic slots and thirty-two diagnostic simulation work units (69 total). The byte bound includes the five-token buffer, generated symbol payload/tag/location upper bounds, state storage, six-state diagnostic copy, four String slots and sixteen bytes per possible expected name. Temporary parser storage does not consume the semantic model-item counter: existing tiny-model definition/origin guards preserve their previous outcomes. The lexer checks source bytes and token-buffer bytes before allocation, and token count before each append. No input-dependent generated allocation exceeds these fixed bounds.

Lexical character scans charge/check every256 bytes (at most259 with a UTF-8 character crossing the boundary), including leading and discarded separator trivia. Iterator delivery checks a cloned control on every token and on the attempted EOF delivery, returning a typed `Cancelled` user error rather than fake EOF. With at most five shifts, only one constant transition separates delivery checkpoints. EOF has two bounded reductions; the first action checks control immediately and every256 bytes while validating the at-most16KiB literal. The accepting second reduction performs no allocating or input-length-dependent work. Controlled tests interrupt actual trivia scanning, generated delivery, the first reduction and UTF-8 literal validation; an exhausted iterator also returns cancellation. No worker timeout is used as parser-accounting evidence.

Only the `parse_definition` facade formats structured failures. Offending byte ranges, bounded static categories and exact authored line/byte columns are retained without rendering arbitrary token payloads or unbounded expected-token lists. Cancellation and resource errors remain typed public terminals. Whole-declaration provenance remains unchanged, while eager expansion uses the generated literal span directly. No-rescan, original-cursor, comment/raw ownership and freeze/registry behavior retain their existing tests.
