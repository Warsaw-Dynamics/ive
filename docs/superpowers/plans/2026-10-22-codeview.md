# codeview Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move IVE's code viewing, editing and diffing into a `codeview` library crate behind an actor-style protocol,
then add piece-table editing with range-based saves, coloured diffs, a side-by-side diff layout and editable
uncommitted diffs.

**Architecture:** `codeview/` is a path-dependency library crate (gpui + tree-sitter) that never imports IVE. IVE talks
to each panel through `Cast` messages, typed call methods and `Event`s; IVE supplies a `Host` global (keys, clipboard,
diff marks) and a `ViewStyle` global (colours, fonts, sizes). Tasks 1–5 move code with no behaviour change; 6 adds the
protocol; 7–10 editing and saving; 11–13 diffs.

**Tech Stack:** Rust 2024, gpui (pgui fork, pinned rev), tree-sitter 0.27, memmap2, serde.

**Spec:** `docs/superpowers/specs/2026-10-22-codeview-crate-design.md` — read it before any task.

## Global Constraints

- `codeview` never `use`s anything from IVE; dependencies point IVE → codeview only.
- Same pinned versions as IVE's `Cargo.toml` for every dependency that moves (gpui rev
  `f5d5fa2f8f07b0be68442e694d22ed6064609e73`, tree-sitter `0.27.1`, every `tree-sitter-*` crate, memmap2, memchr,
  streaming-iterator, unicode-segmentation, serde).
- `codeview/Cargo.toml`: `publish = false`, `license = "LicenseRef-WarsawDynamics-Proprietary"`, `edition = "2024"`.
- Highlight limits unchanged: `MAX_HIGHLIGHT_BYTES = 8 * 1024 * 1024`, `PARSE_BUDGET = 2 s`.
- Diff limits unchanged: `FILE_LINE_LIMIT = 20_000`, `VIEW_LINE_LIMIT = 200_000`, `MAX_FILE_BYTES = 10 MiB`.
- Scratch `SAVE_DELAY = 500 ms`.
- Tests: `should_…` names with `// given`, `// when`, `// then`; moved tests move with their code unchanged.
- Each task ends with `cargo test` (whole workspace) and `cargo clippy --all-targets` clean, from the worktree root.
- UI tasks are also checked in a running IVE over MCP: `./run.sh -- --profile agent-codeview --background .`, the MCP
  tools in README.md; stop the instance afterwards (AGENTS.md).
- Match surrounding code: comment density, naming (British spelling: colour), idioms.

## Review Focus

1. **Tabs and CRLF.** `DisplayLine` shows tabs as 4 spaces and drops `\r`; caret columns, selections and `Edit` byte
   ranges must map through `offset_at`/`column_of` to the file's real bytes, and saving must keep CRLF and tabs as
   they were. Pinned in Task 8 and Task 10.
2. **Bytes that are not UTF-8.** A file with invalid UTF-8 is shown lossily; an edit elsewhere must write the
   untouched invalid bytes back unchanged (pieces reference the original bytes). Pinned in Task 7 and Task 10.
3. **The file changes on disk under an open panel** (truncated, replaced by `git checkout`, deleted). No SIGBUS from
   a stale mmap, no silent overwrite: a save answers `Conflict`. Pinned in Task 10.
4. **A failed write** (read-only file, disk full). Edits stay in the panel, the user sees why, the next pause retries.
   Pinned in Task 10.
5. **Restoring old saved tabs.** A `state.toml` from today's IVE (`scroll`, `caret` fields, no `panel`) restores the
   same scroll and caret; a saved position past the end of a now-shorter file clamps. Pinned in Task 6.

### Task 10: Saving: requests from the panel, writes in IVE

**Files:**
- Create: `src/file_write.rs`
- Modify: `codeview/src/panel/mod.rs`, `src/scratch/tab.rs`, `src/editor.rs` / `src/workspace.rs` (file tabs open

**Interfaces:**
- Panel: after `EditPolicy::save_delay` without edits, on focus leaving, on `Command::Flush`: emits one
  `SaveRequested { base, revision, edits }` (none in flight → send; in flight → remember and send after the answer).
  `Saved` → `rebase(source)` (or keep pieces when `source` is `None`); `SaveFailed` → keep edits, the panel shows a
  bar with the reason, retries after the next pause; `Conflict` → bar with Reload / Overwrite emitting a new

- `src/file_write.rs`:

```rust
pub enum WriteOutcome { InPlace, Rewritten }
pub fn apply_edits(path: &Path, expected: FileStamp, edits: &[Edit]) -> Result<WriteOutcome, WriteError>;
pub enum WriteError { Conflict, Io(io::Error) }
pub fn save_delay(byte_len: u64) -> Duration;
```

  Same-length edits → `pwrite` each in place. Otherwise temp file in the same directory: clone the prefix up to the
  first edit with `libc::ioctl(FICLONERANGE)` (Linux) / `clonefile` on the whole file then rewrite (macOS), falling
